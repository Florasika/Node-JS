🌡️ Convertisseur de Température (Celsius ↔ Fahrenheit)
Description

Ce projet est un petit convertisseur de température réalisé en HTML, CSS et JavaScript.
Il permet de convertir une valeur de Celsius vers Fahrenheit et de Fahrenheit vers Celsius de manière simple et interactive.

Fonctionnalités
Saisie d’une température via un champ input.

Choix de la conversion :
    Celsius → Fahrenheit
    Fahrenheit → Celsius
    Affichage instantané du résultat après clic sur le bouton Convertir.
    Gestion des erreurs pour les entrées non numériques.
    Design responsive et moderne avec gradient et ombre portée.

Technologies utilisées
    HTML5 : structure de la page
    CSS3 : style et mise en forme
    JavaScript (Vanilla JS) : logique de conversion et manipulation du DOM
    Installation / Utilisation

Clone ce dépôt ou télécharge les fichiers :
    git clone <URL-du-repo>
    Ouvre le fichier index.html dans ton navigateur.
    Saisis une valeur dans le champ de température.
    Choisis l’unité de conversion (Celsius → Fahrenheit ou Fahrenheit → Celsius).
    Clique sur Convertir pour voir le résultat.

Améliorations possibles

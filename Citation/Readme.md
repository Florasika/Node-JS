📄 README — Générateur de citations
📌 Description

Le Générateur de citations est une application web simple développée en JavaScript vanilla qui affiche une citation aléatoire à chaque clic sur un bouton.

Ce projet permet de pratiquer les bases du JavaScript :

    manipulation du DOM
    gestion des événements
    utilisation des tableaux et objets
    logique aléatoire
        🚀 Fonctionnalités
        🎯 Afficher une citation aléatoire
        🔁 Changer de citation en cliquant sur un bouton
        ✍️ Afficher l’auteur de la citation
        🎨 Interface simple et responsive

🛠️ Technologies utilisées
    HTML5
    CSS3
    JavaScript (Vanilla)

📁 Structure du projet
    /quote-generator
    ├── index.html
    ├── style.css
    └── script.js

⚙️ Installation et utilisation
    Clone le projet ou télécharge les fichiers
    git clone https://github.com/ton-username/quote-generator.git
    Ouvre le fichier index.html dans ton navigateur

💡 Comment ça fonctionne
    Les citations sont stockées dans un tableau JavaScript
    Lors du clic sur le bouton :
    un index aléatoire est généré
    une citation est sélectionnée

le texte et l’auteur sont affichés dans le DOM
    📈 Améliorations possibles
    🔗 Utiliser une API de citations
    🎨 Ajouter des animations CSS
    🌙 Mode sombre / clair
    📤 Bouton de partage (Twitter, LinkedIn)
    🧠 Éviter les répétitions de citations
    📱 Améliorer le responsive mobile
    🎯 Objectif pédagogique

Ce projet est idéal pour :

    les débutants en JavaScript
    comprendre la manipulation du DOM
    apprendre à structurer un mini projet frontend

# Node-JS
📊 Compteur de clics (JavaScript)

Un mini projet en JavaScript pour apprendre les bases du DOM, des événements et de la manipulation dynamique du contenu.

🚀 Démo

  👉 Clique sur le bouton et regarde le compteur augmenter en temps réel.

🎯 Objectifs pédagogiques

Ce projet m’a permis de comprendre :

La sélection d’éléments avec getElementById
  L’utilisation de addEventListener
  La manipulation du DOM avec textContent
  La gestion d’état avec une variable JavaScript

🛠️ Technologies utilisées
  HTML5
  CSS3
  JavaScript (Vanilla JS)

📂 Structure du projet
  compteur/
  │
  ├── index.html     # Structure de la page
  ├── style.css      # Design et mise en forme
  └── script.js      # Logique JavaScript

⚙️ Fonctionnalités
  ➕ Incrémenter le compteur à chaque clic
  🔁 Réinitialiser le compteur
  🎨 Interface simple et responsive
  ▶️ Installation

Lance le fichier index.html dans ton navigateur.
  💡 Améliorations possibles
  💾 Sauvegarder le compteur avec localStorage
  🎵 Ajouter un son au clic
  🌈 Changer la couleur à chaque clic
  
📊 Ajouter des statistiques ou un graphique
